# ShramAI Data Directory

- `raw/`: Storage for incoming unparsed document uploads (PDF, Scanned PDF, JPEG, PNG).
- `processed/`: Intermediate OCR results, extracted tables, and normalized JSON documents.
- `synthetic/`: Privacy-safe synthetic establishment datasets (compliant, non-compliant, and edge-case registers).
- `legal/`: Ground-truth statutory legal texts, central rules, and notifications for the Four Labour Codes.
